# Project contract

Reproducible, English, descriptive/diagnostic EDA of the UCI "Predict Students' Dropout and Academic Success" dataset, organized as Google's six phases: Ask, Prepare, Process, Analyze, Share, Act. R does acquisition, wrangling, statistics and figures; Quarto renders the report; renv pins packages.

`Target` (Dropout, Enrolled, Graduate) is the nominal outcome; the other original columns are explanatory variables. No predictive modeling, deployment or causal claims.

## Setup

```text
Rscript scripts/bootstrap.R            # install/restore packages from renv.lock
Rscript scripts/bootstrap.R --check    # verify only, never installs
Rscript scripts/run_pipeline.R --check-environment
```

Managed packages: renv, readr, dplyr, tidyr, ggplot2, janitor, here, knitr, rmarkdown, jsonlite, yaml, digest. Quarto is required from the Share stage. If `Rscript` or `quarto` is not on PATH, call it by absolute path; `QUARTO_PATH` overrides discovery. Randomized procedures use seed 20261016.

## Runner

```text
Rscript scripts/run_pipeline.R --through prepare|process|analyze|share|act [--track profile|demographics|academic|all]
```

Stages run in order prepare -> process -> analyze -> share -> act, each with prerequisites. `--track` (default `all`) applies to analyze: a named track runs only that track; `all` runs every track and then integration. Invalid arguments, missing stage files, or failing checks exit nonzero. A stage that is not implemented yet fails explicitly. The full report command is `Rscript scripts/run_pipeline.R --through share`.

## Stage interfaces

| Stage | Entrypoints | Artifacts | Check |
| --- | --- | --- | --- |
| Prepare | scripts/02_prepare.R, R/prepare.R | data/interim/source.rds, metadata/provenance.json, metadata/variables.csv, metadata/category_codes.csv | checks/check_source.R |
| Process | scripts/03_process.R, R/process.R | data/processed/analysis.rds, metadata/column_map.csv, data_dictionary.csv, quality_rules.csv, transformation_log.csv | checks/check_data.R |
| Analyze tracks | scripts/04a_profile.R, 04b_demographics.R, 04c_academic.R | outputs/tables/<track>/, outputs/figures/<track>/ | one check per track |
| Analyze integration | scripts/04_integrate.R, R/analyze.R | outputs/tables/analyze/findings.csv | checks/check_analysis.R |
| Share | reports/eda.qmd, reports/references.bib | _site/ (HTML) | Quarto render |
| Act | docs/action-plan.md, metadata/action_plan.csv | evidence-linked proposals | checks/check_actions.R |

Track evidence CSVs share the columns evidence_id, question_id, source_table, metric, value, numerator, denominator, units, timing_group, with ID prefixes PROFILE, DEMO, ACAD.

## Ownership

Bootstrap owns the runner, environment, lockfile and shared helpers. Each later phase owns only its own scripts, R module, checks, metadata and narrative; shared changes need a named owner. Phase dependencies are linear: Ask and Prepare precede Process, which precedes the three tracks, then integration, Share and Act.

## Data handling

`data.csv` is the immutable tracked source (semicolon-delimited). It is never modified; all transformations are made in R from it and logged. Generated data, tables, figures, logs and `_site/` are git-ignored and regenerated by the pipeline. No automatic deduplication, imputation, outlier removal, normalization or class rebalancing.
